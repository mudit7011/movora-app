# Movora

Native Movora app for Windows, macOS and Android: real 4K HDR, Dolby Vision, Hindi audio and subtitles in one clean player.

Download the latest build from [Releases](https://github.com/mudit7011/movora-app/releases/latest) or from [watchmovora.com/download](https://watchmovora.com/download).

- **Windows:** download `Movora-Windows.zip`, extract it, run `Movora.exe`. If SmartScreen shows a warning, click More info, then Run anyway.
- **macOS:** open `Movora-macOS.dmg` and drag Movora to Applications. The first time, open System Settings, Privacy & Security, and click Open Anyway.
- **Android:** install `Movora-Android.apk` (allow installs from your browser when asked).
